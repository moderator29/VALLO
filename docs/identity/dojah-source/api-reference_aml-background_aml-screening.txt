# AML screening

> Screen an individual against global PEP, sanctions, warning and adverse-media lists. Match details come back on the same response.

POST
`/api/v2/aml/screening`

Screen an individual against global PEP, sanctions, warning and adverse-media lists — across 200+ countries and 40,000+ databases. The response includes every match.

This is the same endpoint as [Business AML screening](https://docs.dojah.io/api-reference/aml-background/business-screening.md). Set `schema` to `"individual"` here, and to `"organization"` when you are screening a business.

## Headers

| Header | Required | Description |
| - | - | - |
| `Authorization` | Yes | Your app's secret key, sent as-is — *not* `Bearer`. |
| `AppId` | Yes | The App ID from your dashboard. |
| `Content-Type` | Yes | `application/json` |

## Body parameters

| Parameter | Type | Required | Description |
| - | - | - | - |
| `schema` | string | Yes | `"individual"` for a person. Use `"organization"` to [screen a business](https://docs.dojah.io/api-reference/aml-background/business-screening.md). |
| `unique_reference` | string | No | Your own reference for the request, echoed back for reconciliation. |
| `properties.names` | string | Yes | The full name to screen (e.g. `"David Ukpo"`). |
| `properties.gender` | string | No | e.g. `"male"` — narrows the candidate set. |
| `properties.date_of_birth` | string | No | e.g. `"12-10-2000"`. Strengthens match scoring. |
| `properties.nationality` | string | No | The subject's nationality (e.g. `"Nigerian"`). |
| `properties.id_number` | string | No | A government-issued ID number. Send `""` when you don't have one. |
| `screening_options.pep_check` | boolean | No | Screen against politically-exposed-person registries. |
| `screening_options.sanction` | boolean | No | Screen against sanctions lists. |
| `screening_options.adverse_media_check` | boolean | No | Screen against adverse media. |
| `screening_options.watchlists` | array | No | Specific [watchlist codes](#watchlist-codes). Omit the field or send `[]` to search all lists. |
| `screening_options.match_threshold` | number | No | Minimum match score to return. `1` is the highest (e.g. `0.85`). |

## What gets screened

Every result carries a `source_type` identifying which kind of list it came from:

| Category | What it covers |
| - | - |
| `PEP` | Politically exposed persons — current and former office-holders and their close associates. |
| `Sanctions` | Global and regional sanctions and embargo lists (OFAC, UN, EU and more). |
| `Adverse Media` | Negative news — grouped by `media_category` (e.g. `violent_crime`, `terrorism`, `political`, `financial_crime`, `organized_crime`) with the underlying articles. |
| `Warning` | Regulatory and law-enforcement warning lists. |

The overall record is graded with a `risk_level` (e.g. Low / Medium / High) and a `match_status` — one of **No Match**, **Partially Matched**, **Potential Match** or **Confirmed Match**.

## Watchlist codes

Pass these values in `screening_options.watchlists`. Omit the field or send `[]` to search every list.

| Code | List |
| - | - |
| `OFAC_SDN` | US Treasury OFAC Specially Designated Nationals. |
| `EU_Terrorist` | European Union terrorist sanctions list. |
| `IndSancList` | Nigeria Sanctions Committee list of designated individuals. |

## Response

Returns an `entity` with the `search_query`, `total_results` / `total_articles` counts, an overall `risk_level` and `match_status`, a `match_level`, a `weak_results` count, and a `results` array.

A **profile match** (`source_type` such as `"PEP"` or `"OTHER"`) can include `name`, `titles`, `alias_names`, `given_names`, `last_names`, `gender`, `date_of_birth`, `place_of_birth`, `country`, `address`, `positions`, `education`, `other_information`, `urls`, and `relations`. Each profile has `match` and `match_strength` (e.g. `"confirmed"`).

**Adverse-media** hits are grouped by `source_type: "ADVERSE_MEDIA"` and `media_category`. Each article has a `timestamp`, `headline`, `source`, and HTML `body`. The example opposite is trimmed; the live response includes every profile, every article, and the full body.

## Errors

| Code | Meaning |
| - | - |
| `400` | Bad request — a required field is missing or malformed. |
| `401` | Unauthorized — check your key and `AppId` (no `Bearer` prefix). |
| `402` | Insufficient wallet balance. [Fund your wallet](https://docs.dojah.io/api-reference/core-concepts/wallet-billing.md). |
| `429` | Too many requests — back off and retry. |

```bash cURL theme={null}
curl -X POST "https://api.dojah.io/api/v2/aml/screening" \
  -H "Authorization: {{secret_key}}" \
  -H "AppId: {{app_id}}" \
  -H "Content-Type: application/json" \
  -d '{
    "schema": "individual",
    "unique_reference": "123450987qwergoidavid",
    "properties": {
      "names": "David Ukpo",
      "gender": "male",
      "date_of_birth": "12-10-2000",
      "nationality": "Nigerian",
      "id_number": ""
    },
    "screening_options": {
      "pep_check": true,
      "sanction": true,
      "adverse_media_check": true,
      "watchlists": ["OFAC_SDN", "EU_Terrorist", "IndSancList"],
      "match_threshold": 0.85
    }
  }'
```

const res = await fetch("https://api.dojah.io/api/v2/aml/screening", {

      names: "David Ukpo",
      gender: "male",
      date_of_birth: "12-10-2000",
      nationality: "Nigerian",
      id_number: "",
    },
    screening_options: {
      pep_check: true,
      sanction: true,
      adverse_media_check: true,
      watchlists: ["OFAC_SDN", "EU_Terrorist", "IndSancList"],
      match_threshold: 0.85,
    },
  }),
});
const data = await res.json();

```python Python theme={null}
import os, requests

res = requests.post(
    "https://api.dojah.io/api/v2/aml/screening",
    headers={
        "Authorization": os.environ["DOJAH_SECRET_KEY"],
        "AppId": os.environ["DOJAH_APP_ID"],
    },
    json={
        "schema": "individual",
        "unique_reference": "123450987qwergoidavid",
        "properties": {
            "names": "David Ukpo",
            "gender": "male",
            "date_of_birth": "12-10-2000",
            "nationality": "Nigerian",
            "id_number": "",
        },
        "screening_options": {
            "pep_check": True,
            "sanction": True,
            "adverse_media_check": True,
            "watchlists": ["OFAC_SDN", "EU_Terrorist", "IndSancList"],
            "match_threshold": 0.85,
        },
    },
)
data = res.json()
```
